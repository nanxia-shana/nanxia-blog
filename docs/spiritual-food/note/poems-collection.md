# 古诗词集

<span class="Serif-SC-Font">风月无古今，情怀自浅深。</span>

<span class="Serif-SC-Font">古人写下的诗句，穿越千年而来，依然能触动我们的心弦。</span>

<span class="Serif-SC-Font">这里收集的，是我喜欢的那些词句。</span>

## 唐代

### 张若虚

<Poem
  title="春江花月夜"
  author="张若虚"
  dynasty="唐"
  :lines="[
    '春江潮水连海平，海上明月共潮生。',
    '滟滟随波千万里，何处春江无月明。',
    '江流宛转绕芳甸，月照花林皆似霰。',
    '空里流霜不觉飞，汀上白沙看不见。',
    '江天一色无纤尘，皎皎空中孤月轮。',
    '江畔何人初见月？江月何年初照人？',
    '人生代代无穷已，江月年年望相似。',
    '不知江月待何人，但见长江送流水。',
    '白云一片去悠悠，青枫浦上不胜愁。',
    '谁家今夜扁舟子？何处相思明月楼？',
    '可怜楼上月徘徊，应照离人妆镜台。',
    '玉户帘中卷不去，捣衣砧上拂还来。',
    '此时相望不相闻，愿逐月华流照君。',
    '鸿雁长飞光不度，鱼龙潜跃水成文。',
    '昨夜闲潭梦落花，可怜春半不还家。',
    '江水流春去欲尽，江潭落月复西斜。',
    '斜月沉沉藏海雾，碣石潇湘无限路。',
    '不知乘月几人归，落月摇情满江树。',
  ]"
  notes="张若虚，初唐诗人，与贺知章、张旭、包融并称“吴中四士”。其诗仅存两首传世，《春江花月夜》便是其中之一。此诗被闻一多誉为'诗中的诗，顶峰上的顶峰'。它将春江、花月、夜色融为一体，意境幽远深沉，既有对自然美的赞叹，也有对人生哲理的思考。张若虚也因此诗“孤篇横绝，竟为大家”。"
/>

## 明代

### 杨慎

<Poem
  title="临江仙"
  author="杨慎"
  dynasty="明"
  :lines="[
    '滚滚长江东逝水，浪花淘尽英雄。',
    '是非成败转头空。',
    '青山依旧在，几度夕阳红。',
    '白发渔樵江渚上，惯看秋月春风。',
    '一壶浊酒喜相逢。',
    '古今多少事，都付笑谈中。',
  ]"
  notes="杨慎，明代三大才子之首，父亲杨廷和是正德、嘉靖两朝的内阁首辅。杨慎二十四岁即状元及第，本应仕途坦荡，却因“大礼议”事件得罪嘉靖皇帝，被廷杖后流放云南永昌卫，时年三十七岁。这首《临江仙》便是他在流放途中所作。仕途终结，人生巨变，站在江边长叹历史兴亡，才有了“滚滚长江东逝水”的开篇。后来毛宗岗评刻《三国演义》时，将此词置于卷首，从此家喻户晓。杨慎在云南度过了三十余年的流放生涯，终其一生未能还乡，却也因此著书立说，留下了浩瀚的文字。"
/>
